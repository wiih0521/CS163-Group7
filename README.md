# CS163-Group7

Project: Data Structures Viualizer

Group: 07

## Build and Run (Windows - MinGW)

Make sure you have **CMake**, **MinGW (g++)**, and **SFML** installed and added to PATH.

Run the following commands in terminal:

```bash
git clone https://github.com/wiih0521/CS163-Group7.git
cd CS163-Group7/CS163-Group7
mkdir build
cd build
cmake -G "MinGW Makefiles" ..
cmake --build .
.\CS163-Group7.exe
```
